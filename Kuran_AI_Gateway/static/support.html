Support

Help and support for the Kuran AI application.

How to Get Help

For technical issues, subscription questions, or account assistance, please visit our Contact page and fill out the support form. We'll get back to you as soon as possible.

Frequently Asked Questions

  • Login issues (Google/Apple): Make sure you're using the same account you registered with. If the issue persists, contact us with your email and sign-in method.
  • Subscription not showing: Try "Restore Purchases" first. If it still doesn't appear, ensure you're signed in with the same Apple ID.
  • Cancel subscription: Settings → Apple ID → Subscriptions → Kuran AI → Cancel.
  • Refund: Visit reportaproblem.apple.com.
  • Delete account: Profile → Security Settings → Delete Account.
  • App crashes: Update to the latest version. If it persists, contact us with your device model and iOS version.
