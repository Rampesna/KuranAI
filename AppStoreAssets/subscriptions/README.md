# App Store Subscription Promotional Artwork

These files are the 1024 × 1024 promotional images uploaded to App Store
Connect for KuranAI's auto-renewable subscriptions. Each image is intentionally
different from the KuranAI app icon and from every other subscription image.

Do not replace these files with the app icon. Apple rejected the July 2026
submission under Guideline 2.3.2 when `logo_with_bg.png` was used as the
promotional image for Bronze Yearly.
